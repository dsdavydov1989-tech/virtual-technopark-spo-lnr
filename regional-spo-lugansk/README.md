# Виртуальный технопарк СПО ЛНР — проект сайта

Откройте `index.html` в браузере: сайт работает без сборки и сервера. Для локального просмотра через HTTP из этой папки: `python -m http.server 8000`, затем перейдите на `http://localhost:8000/`.

## Состав

- `index.html`, `styles.css`, `redesign.css`, `script.js` — адаптивный сайт; каталог техники, пять учебных УП и схем деталей, обзор БАС с проектным учебным маршрутом, фильтр направлений, переключатель этажей и мобильное меню.
- `assets/cnc-part-*.svg` — пять авторских схем деталей для раздела примеров управляющих программ.
- `assets/campus-future.svg` — авторский футуристический эскиз кампуса в Луганске.
- `assets/cluster-*.jpg` — локальные копии фотографий из официальных фотогалерей СПЭТ.
- `assets/floor-plans.svg` — функциональные схемы трёх этажей для просмотра и скачивания.
- `assets/catalog-*.jpg` — локальные копии фотографий оборудования из каталога Deria (ссылки на страницы моделей даны в карточках).
- `КОНЦЕПЦИЯ_И_ЭСКИЗНЫЙ_ПРОЕКТ.md` — задачи центра, предварительные параметры здания, функциональная программа и этапы разработки.

Сайт «Виртуальный технопарк СПО ЛНР» представляет **концепцию** регионального центра, а не официальный портал действующей организации. Точный адрес, реквизиты и расписание мероприятий не придуманы и появятся только после утверждения проекта.

В качестве отраслевого ориентира использована [страница федеральных технопарков ИРПО](https://firpo.ru/activities/technopark/about/) с информацией о площадке в Калуге. Дизайн и эскиз луганского центра созданы отдельно.

Раздел БАС опирается на [материалы Росавиации](https://favt.gov.ru/dejatelnost-bas/) и [проект ИРПО по оснащению образовательных организаций для подготовки в сфере БАС](https://firpo.ru/activities/projects/federalnyy-proekt-professionalitet-copy/). Примеры применения и типы аппаратов носят обзорный характер; учебный маршрут для центра предложен как концепция.

## Публикация на GitHub Pages

Публичный репозиторий содержит файлы сайта в корне ветки `master`. GitHub Pages публикует сайт напрямую из этой ветки. Перед обновлением сайта проверьте локальные ссылки командой `python verify_site.py`.

Адрес опубликованного сайта: `https://dsdavydov1989-tech.github.io/virtual-technopark-spo-lnr/`.
